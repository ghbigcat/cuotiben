# 错题本 · 拍 录 做 批 斩

一个纯静态的错题管理网页：拍照或截图录题、自动切分整页试卷、按间隔推送重做、判定对错、连对两次才「斩」题，最后能按学科分册导出 PDF 打印装订。

**直接用**：打开 <https://ghbigcat.github.io/cuotiben/>

**在 iPhone 上装成 App**：Safari 打开上面的链接 → 底部「分享」→「添加到主屏幕」。之后从主屏点开是全屏无地址栏，和原生 App 一样。

无需注册、无需联网（除可选的 AI 识别）、不采集任何数据。所有题目和图片只存在**你自己浏览器的本地存储**（IndexedDB）里，不上传服务器。

## 分享给别人用

三种给法，按对方的目的选：

| 场景 | 给对方什么 | 说明 |
|---|---|---|
| 只是自己用 | 网页链接 <https://ghbigcat.github.io/cuotiben/> | 最省事。对方打开即用，不用装、不用注册 |
| 想离线备用 | 仓库页 → Code → Download ZIP，解压后双击 `index.html` | 手机上需用支持本地 html 的浏览器 |
| 想改代码 | `git clone https://github.com/ghbigcat/cuotiben.git` | 无框架无构建，改完刷新即生效 |

**给出去之前对方要知道的一件事：数据不互通。** 每个人的题目存在各自浏览器的本地存储里，彼此看不到；同一台设备换浏览器、清缓存也会丢。跨设备迁移只能靠「设置 → 导出备份 / 导入备份」的 JSON 文件。

AI 识别是可选的，用的人要填自己的 API Key（设置页），不填也能手动录题、手动判对错。

## 五步循环

1. **拍** — 拍照 / 相册 / 粘贴截图 / 拖拽，四个入口
2. **录** — 一张卷子多道题时切到「整页切题」，拍一页自动切成多块，可拖动调整边界
3. **做** — 次日开始推送重做，先自己做再上传作答照
4. **批** — AI 判定或自己判；错了累计错次 +1
5. **斩** — 连对两次且间隔 3 天以上，才解锁「斩掉这题」

## 关键规则

| 规则 | 实现 |
|---|---|
| 反复错 | 累计错次 ≥ 2 自动标记 |
| 斩题门槛 | `streak ≥ 2` 且间隔 ≥ 3 天 + 人工判断「讲得清」 |
| 复习间隔 | 固定间隔（1 / 2 / 3 / 7 天），不用 SM-2 |
| 每日题额 | 默认 3 题，封顶 15 题，可调 |

## 数据安全

题目存在浏览器本地，**换浏览器、换设备、清缓存都会丢**。

- 设置页 → 「导出备份」得到 JSON
- 换设备 / 换浏览器后 → 「导入备份」合并回来
- 别用无痕模式打开

## AI 识别（可选）

设置页填 OpenAI 兼容接口的 baseURL、模型名、API Key（需支持图片输入）。不配也能用，手动填学科、知识点、错因码即可。

## 导出 PDF

题库页右上角「导出 PDF · 打印」→ 选学科和范围 → 生成 A4 预览 → 打印对话框里把目标改成「另存为 PDF」。

页数估算用真实 DOM 测量 + 贪心装箱模拟，实测误差 0 页。

## 结构

```
index.html      界面骨架（5 个视图）
app.css         iOS 风格设计令牌与样式 + 打印版式
js/db.js        IndexedDB（不可用时降级 localStorage）
js/app.js       业务规则、视图渲染、事件绑定
js/batch.js     整页切题：Otsu 二值化 + 行投影 + 最大跳变找切点
js/pdf.js       PDF 导出：A4 排版、页数测量、打印
```

无框架、无构建、无依赖，改完刷新即生效。
